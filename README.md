# 다 했어요

아이가 아침과 저녁에 할 일을 한 번 터치해서 표시하고, 걸린 시간을 기록하는 웹 앱입니다.

- 주소: https://unclehoho.github.io/dahaesseoyo/
- 아이패드·아이폰: 사파리에서 주소를 열고 공유 → "홈 화면에 추가"
- 갤럭시: 크롬에서 주소를 열고 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
- 이름과 기록은 앱을 쓰는 기기 안에만 저장됩니다. 이 저장소에는 앱 파일만 있습니다.

## 파일

- `index.html` 앱 전체 (그림 포함)
- `manifest.webmanifest`, `icons/` 홈 화면 아이콘과 설치 정보
- `sw.js` 인터넷이 끊겨도 열리게 하는 보관 스크립트
